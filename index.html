The contract

One file. Two required fields. Infinite portability.

Every Agent Skill is a folder with a SKILL.md at its root. YAML frontmatter on top, markdown instructions below, optional sibling scripts and references that load only when needed.

The standard is intentionally minimal — master the required fields and the cross-client convention, then add platform-specific extras only when they earn it.

~/.agents/skills/pdf-processing/SKILL.md 
---
name: pdf-processing
description: Extract text and tables from PDF
  files, fill forms, merge documents.
  Use when working with PDF files or
  when the user mentions PDFs, forms,
  or document extraction.
license: Apache-2.0
---

# PDF Processing

Use pdfplumber for text extraction:

```python
import pdfplumber
with pdfplumber.open("file.pdf") as pdf:
    text = pdf.pages[0].extract_text()
```

For form filling, see [FORMS.md](FORMS.md).
How it scales

Install hundreds of skills. Pay for the ones you actually use.

ติดตั้ง Skill ได้เป็นร้อยตัว · จ่าย token เฉพาะที่ใช้จริง

Progressive disclosure loads skills in three tiers — agents see metadata at startup, instructions on activation, and bundled resources only on demand.

Tier 1 · Always

Metadata

name + description from every installed skill — preloaded into the system prompt at session start.

~100 tokens / skill
Tier 2 · On match

Instructions

Full SKILL.md body loads when the agent decides the skill is relevant to the current task.

< 5,000 tokens
Tier 3 · On demand

Resources

Bundled scripts/, references/, assets/ read only when the instructions need them.

~unbounded

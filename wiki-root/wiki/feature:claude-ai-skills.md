# Skills in claude.ai

## Summary

claude.ai supports both pre-built Skills (already integrated invisibly behind document-creation features) and custom Skills uploaded as ZIP files through Settings → Features. Custom Skills are **per-user** — there is currently no centralised admin/org distribution.

## Claims

- Pre-built Skills always running (PowerPoint, Excel, Word, PDF). `[src: raw/2026-05-08-platform-docs-overview.md] {conf: 0.9}`
- Custom Skill uploads are individual; teammates must each upload separately. `[src: raw/2026-05-08-platform-docs-overview.md] {conf: 0.95}`
- Available on Pro, Max, Team, Enterprise plans (with code execution enabled). `[src: raw/2026-05-08-platform-docs-overview.md] {conf: 0.9}`
- Network access varies by user/admin policy. `[src: raw/2026-05-08-platform-docs-overview.md] {conf: 0.85}`
